# MY MONEY v1.0

Your money. Your future. 아이폰·PC에서 사용하는 재정관리 PWA입니다.

## 포함된 기능

- 거래 수입/지출/이체 입력·수정·삭제, 거래와 계좌 잔액 연동
- 월별 지출 예산 관리, 지출 분석, 6개월 현황
- 저축 목표 추가·수정·저축액 증감 관리
- 수동 계좌 관리, 정기 결제 관리, 카테고리 관리
- 브라우저 로컬 저장, JSON 전체 백업/복원, CSV 거래 내보내기
- 선택적 Supabase 이메일 로그인과 사용자별 클라우드 동기화
- 아이폰 홈 화면에 설치 가능한 PWA, 오프라인 앱 파일 캐싱

## 빠른 시작

1. `index.html`과 `style.css`, `app.js`를 동일 폴더에 둡니다.
2. 테스트: `python -m http.server 8000` 명령을 해당 폴더에서 실행한 다음 http://localhost:8000 접속.
3. 또는 `MY_MONEY_단일파일.html`을 브라우저에서 직접 엽니다(이 파일은 서비스 워커와 설치 매니페스트가 없음).
4. 기본 화면은 명확히 라벨된 **가상 샘플 데이터**입니다. '내 기록 시작'을 눌러 빈 장부를 만드세요.
5. GitHub Pages에 `index.html`, `style.css`, `app.js`, `manifest.webmanifest`, `sw.js`, `icons/`를 배포하면 iPhone Safari > 공유 > 홈 화면에 추가로 설치할 수 있습니다.

## 실제 클라우드 로그인 연결

**이 단계는 사용자의 Supabase 프로젝트 생성이 필요합니다. 코드가 자체적으로 서버를 만들거나 계정을 개설하지는 않습니다.**

1. https://supabase.com/dashboard 에서 본인 프로젝트 생성.
2. SQL Editor에서 `supabase.sql` 전체 실행.
3. Authentication > Providers에서 이메일 인증과 원하는 가입/인증 정책 확인.
4. Settings / API Keys에서 프로젝트 URL과 **publishable 또는 anon (공개)** 키를 확인.
5. 앱 > 설정 > 클라우드 로그인 및 동기화 > URL/공개 키 저장, 이메일 가입/로그인.
6. 최초 로그인 시 **빈 클라우드 장부**가 생성됩니다. 기기의 로컬 데이터를 가져올 때는 클라우드 페이지의 '이 기기의 로컬 기록 업로드'를 사용합니다. 업로드 전 로컬/클라우드 JSON 백업을 권장합니다.
7. 두 기기 모두 같은 URL/키를 설정하고 같은 사용자 이메일로 로그인합니다.

**절대 `service_role` 또는 `sb_secret_...` 키를 프론트엔드에 입력하거나 GitHub에 올리지 마세요.** RLS 정책이 실제로 작동하는지 본인 및 별도 테스트 계정으로 검증하기 전 민감한 실거래 데이터를 입력하지 마세요. 현재 버전에서는 앱 브라우저 캐시와 로컬 스토리지에 일부 재정 데이터·세션 토큰이 남습니다. 기기 잠금과 브라우저 보안이 중요합니다.

## 데이터 저장 및 한계

- 로컬 모드: `localStorage` 저장. 브라우저 저장 데이터를 삭제하면 기록도 사라집니다. 정기적으로 JSON 백업이 필요합니다.
- 클라우드 모드: Supabase PostgreSQL + RLS 저장. 로컬 캐시도 저장되며 서버 연결 실패 중 편집은 나중에 동기화될 수 있습니다. 동일 계정 두 기기에서 동시 편집하면 마지막 저장이 우선될 수 있습니다. 충돌 병합은 구현되어 있지 않습니다.
- JSON 백업 파일은 암호화되지 않습니다. 보안 저장소에 보관해 주세요.
- 저축 목표의 금액은 목표 진척도의 *메모*로, 은행 잔액을 차감하지 않습니다.
- 정기 결제는 목록만 제공하며 자동 거래 입력이나 실제 결제 취소는 하지 않습니다.
- 은행 계정이나 카드사에 접속하지 않습니다. 모든 거래는 사용자가 수동 입력합니다.
